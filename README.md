# CineClash

电影相关的实验项目集合。

## 项目

| 目录 | 说明 | 状态 |
| --- | --- | --- |
| [movie-rating-duel](movie-rating-duel/) | 电影 Elo 对决评分器：用二选一建立个人排行榜 | v0.1.0 · 内核与文档就绪，界面待开发 |

## 开始使用

```bash
cd movie-rating-duel
npm test     # 单元测试
npm start    # 60 场对决模拟，打印排行榜
```

## 协作约定

每个子项目根目录的 `AGENTS.md` 定义该子项目的规则（目录职责、测试要求、提交规范）。
修改代码前请先阅读对应的 `AGENTS.md`，例如 [movie-rating-duel/AGENTS.md](movie-rating-duel/AGENTS.md)。
